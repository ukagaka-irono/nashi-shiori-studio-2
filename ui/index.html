ゴーストの設定

書き出しや SSP に入れるときのフォルダの名前です。はじめて書き出したときに決まり、 あとでゴースト名を変えても同じフォルダに入ります。空ならゴースト名を使います。

ネットワーク更新に使う URL です。書き出したフォルダを丸ごと置く場所を、 うしろに / を付けて入れます。空ならネットワーク更新はしません。

ランダムトーク

直近に出したトークを、この数だけ次の抽選からはずします。おまかせのときはトーク数の半分（最大8）です。

話しかた

「、」のあとは少し、「。」「！」「？」のあとは長めに間を置いて、区切って話すようにします。ためすでも同じように話します。

立ち絵の画像

用意した PNG を割り当てられます。えらばなかった番号は、下の色で自動生成します。

着せ替え

服やリボンなどの部品の PNG を、そのキャラのすべての表情に重ねます。SSP の右クリックメニューで付けはずしでき、「着せ替え ◯ をつける」ブロックでも変えられます。

うごき（アニメーション）

立ち絵をパラパラ切りかえて動かします。「うごき N を再生する」ブロックで呼べます。

見た目（仮シェル）

絵を用意していないときは、この色でかんたんな立ち絵を自動生成します。

「バルーンも作る」を入れると、この色のかんたんな吹き出しを同梱します。 入れないと、使う人が持っているバルーンで表示されます。

変数

好感度やフラグなど、ゴーストが覚えておく値です。終了時に自動で保存されます。

さがす

セリフ・変数・トーク名などから探します（Ctrl+F）。 クリックすると、そのブロックまで移動します。言葉を入れないときは、かたまりの一覧が出ます。

チェック

おかしなところを探します。クリックすると、そのブロックまで移動します。

SSP に入れる

SSP の ghost フォルダへ直接書き出して、そのまま切り替えます。

フォルダ／.nar に書き出す

シェルの surfaces.txt と descript.txt は、なしスタジオが書き出したものなら毎回書き直します。 ここに印を付けると、自動で描いた立ち絵やバルーンの絵と、手で直したシェルのファイルも上書きします。

読み込み

書き出し済みのゴースト（ghost.json）を読み込んで編集できます。

えらぶと、画面を読みなおします。作っているゴーストのセリフは変わりません。

つかいかた

  1. 新規で、お手本か空かをえらびます。お手本は、動くゴーストを見ながらまねて作れます。
  2. イベントから「起動したとき」などをキャンバスにドラッグし、その下にセリフの「…と話す」をつなげます。
  3. ためすタブの ▶ で、その場で動きを見られます。
  4. 右上の「▶ SSP に入れて動かす」で、SSP に入れて動かします。フォルダや .nar は書き出しタブから作れます。
  5. チェックタブに気になるところが出ます。クリックするとその場所へ移動します。

できること

  • 「なでられたとき」などのマウス操作は、あたま・かお・むねといった場所ごとに分けられます。 自分の絵には、ゴーストタブの「立ち絵の画像」の各行にある「当たり判定」で場所を描けます。
  • 立ち絵はゴーストタブで PNG をえらぶか、土台と表情の絵を重ねて作れます。
  • ゴーストタブの「着せ替え」で、服などの部品を SSP の右クリックメニューから付けはずしできます。
  • 選択肢はセリフに、文字や日付をたずねる・◯秒後によぶ・SSP の情報をたずねる、は制御にあります。
  • ほかのゴーストとの会話は、イベントの「話しかけられたとき」とセリフの「話しかける」で作れます。

ブロックの色

キーボードとマウス

  • Ctrl+S 保存
  • Ctrl+Z / Ctrl+Y 元にもどす / やりなおす
  • Ctrl+F さがす
  • Ctrl+C / X / V ブロックのコピー / 切り取り / はりつけ
  • Ctrl+D えらんだブロックを複製
  • Delete えらんだブロックを削除
  • Tab ブロックのつぎの欄へ
  • Shift+Enter セリフを広げて書く
  • Alt+↓ ▾ の付いた欄で、一覧からえらぶ（↑ ↓ で動いて Enter）
  • Esc ダイアログやメニューを閉じる
  • Enter ためすの立ち絵で、いまのセリフを最後まで出す
  • 右クリック 複製・削除・はりつけ・メモを置くメニュー
  • マウスをのせる ブロックの説明を見る（パレットの上の欄で、ブロックをさがせる）
  • ホイール キャンバスを動かす（中ドラッグ・空いた場所のドラッグでも）
  • Ctrl+ホイール 拡大・縮小
  • パレットのふち ドラッグか ← → で幅を変える（ダブルクリックか Home で元の幅にもどす）

栞について

書き出したゴーストは nashi.dll（なし栞 2）で動きます。会話データは ghost/master/ghost.json に入っていて、SSP を動かしたまま書き出し直すと 数秒で自動的に読み込み直されます。
